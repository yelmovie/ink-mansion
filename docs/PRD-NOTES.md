# 잉크저택

> 같은 저택에서 시작하지만, 같은 이야기는 하나도 없다.

**잉크저택**은 초등 국어 수업을 위한 태블릿 기반 **창의 글쓰기 × 방탈출 웹게임**입니다.  
학생은 정해진 이야기를 따라 쓰는 대신, 저택에서 자신이 중요하다고 생각한 단서를 고르고, 단서의 의미를 스스로 해석하고, 인물과 사건을 설계한 뒤 자신만의 이야기와 결말을 완성합니다.

# 왜 태블릿으로 해야 하나요?

이 프로젝트는 종이 학습지의 문제를 화면으로 옮기는 방식이 아닙니다.

학생은 게임에서 직접:

- 어두운 저택을 손전등으로 탐색하고
- 물건을 확대·회전하고
- 숨은 흔적을 문질러 찾고
- 단서를 탐정 가방으로 끌어 넣고
- 관련 있는 단서끼리 선을 연결하고
- 이야기 카드를 조합하고
- 레버와 다이얼을 조작하고
- 장면을 끌어 순서를 바꾸고
- 직접 문장을 작성하고
- 문장을 이동·삭제·수정하고
- 자신의 결말을 만들어 냅니다.

즉, **탐색 → 조작 → 추리 → 설계 → 쓰기 → 퇴고 → 완성**의 전 과정이 게임 플레이입니다.

---

# 핵심 철학

## 정답 이야기가 없습니다

같은 단서를 발견해도 학생마다 다르게 해석할 수 있습니다.

예를 들어 ‘낡은 열쇠’는:

- 비밀방 열쇠일 수도 있고
- 미래로 가는 열쇠일 수도 있고
- 아무것도 열지 못하는 가짜 열쇠일 수도 있고
- 누군가 일부러 남긴 함정일 수도 있습니다.

게임은 어느 해석이 정답인지 판정하지 않습니다.

## 30명이 30개의 다른 이야기를 만들 수 있는 구조

백엔드 없이 다른 학생의 결과와 실시간 비교해 서로 다른 결과를 강제할 수는 없습니다.  
대신 다음 요소가 학생마다 다른 이야기로 갈라지도록 설계합니다.

- 세션별 랜덤 단서 노출
- 학생이 직접 고르는 핵심 단서
- 단서 의미 자유 입력
- 주인공/목표/방해/비밀 조합
- 모든 단계의 `직접 만들기`
- 랜덤 WHAT IF 사건
- 자유로운 장면 수와 순서
- 자유 글쓰기
- 결말 방식 선택 또는 완전 자유 결말

**완성 문장을 고르는 것만으로 게임을 끝낼 수 없도록 설계합니다.**

# 5스테이지 / 10페이지

## Stage 1 — 발견

### 1. 저택 입장
자유 탐색으로 자신이 흥미롭게 생각한 단서를 찾습니다.

상호작용:
- 손전등
- 터치 탐색
- 문지르기
- 드래그 수집

### 2. 심층 탐색
찾은 물건을 자세히 관찰합니다.

상호작용:
- 확대·축소
- 회전
- 밀기
- 환경음 듣기
- 관찰 메모

---

## Stage 2 — 해석

### 3. 단서 해석실
같은 단서를 여러 가지 의미로 해석합니다.

상호작용:
- 단서 연결
- 보드 회전
- 가설 생성
- 자유 입력

### 4. 이야기 씨앗
이야기의 핵심 요소를 만듭니다.

요소:
- 주인공
- 원하는 것
- 방해하는 것
- 비밀

모든 항목은 카드 선택 또는 직접 작성이 가능합니다.

---

## Stage 3 — 변주

### 5. 만약의 방
예상하지 못한 사건을 추가해 뻔한 이야기 흐름을 깨뜨립니다.

선택:
- 받아들이기
- 다시 뽑기
- 직접 만들기

### 6. 장면 설계판
자신의 이야기 장면을 직접 구성합니다.

상호작용:
- 장면 이동
- 추가
- 삭제
- 복제
- 연결
- 순서 변경

---

## Stage 4 — 창작

### 7. 살아나는 글쓰기
학생이 직접 이야기를 씁니다.

게임은 문장을 대신 작성하지 않습니다.

장면 의도:
- 발견
- 갈등
- 대화
- 추적
- 회상
- 반전
- 감정

선택한 장면 의도에 따라 게임 화면의 연출만 달라집니다.

### 8. 퇴고 전투
잉크 괴물과 싸우며 자신의 글을 고쳐 씁니다.

점검:
- 문장 반복
- 문장 부호
- 문단
- 연결 표현
- 내용 보충
- 문장 이동

‘정답 문장’으로 교체하는 활동이 아닙니다.

---

## Stage 5 — 완성

### 9. 결말의 문
결말의 내용을 고르는 것이 아니라 결말의 **방식**을 참고합니다.

- 해결되는 결말
- 열린 결말
- 반전 결말
- 처음과 연결되는 결말
- 나만의 결말

최종 내용은 학생이 직접 작성합니다.

### 10. 이야기 완성
완성한 원고를 제본하고 창작 배지를 받습니다.

기능:
- 내 이야기 전체 보기
- 로컬 저장
- 텍스트 파일 저장
- 인쇄
- 새 이야기 시작

**친구 이야기 보기 / 학급 온라인 서가 기능은 사용하지 않습니다.**

# 콘텐츠 제작 원칙

1. 정답 이야기를 만들지 않는다.
2. 학생 문장을 대신 작성하지 않는다.
3. 모범 문장을 학생 작성 전에 보여주지 않는다.
4. 선택지마다 `직접 만들기` 가능성을 둔다.
5. 이상한 상상도 오답 처리하지 않는다.
6. 피드백은 정답이 아니라 질문으로 제공한다.
7. 글의 창의성을 점수화하지 않는다.
8. 이미지 속 한글 UI 사용을 최소화하고 실제 UI는 CSS/DOM으로 구현한다.
9. 1이미지 = 1에셋 원칙을 지킨다.
10. 태블릿 상호작용이 학습 과정 자체가 되도록 한다.
