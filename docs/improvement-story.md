# 잉크저택 기능 향상기

첫 완성본을 교실 태블릿 기준으로 다시 점검하면서 다섯 가지를 손봤습니다. 모두 "교실에서 실제로 돌아가는가"라는 한 가지 질문에서 나온 개선입니다.

## 잉크 괴물, 코드에서 그림으로

퇴고 단계의 잉크 괴물은 처음에 CSS 도형(원과 그라디언트)을 조합해 코드로 그렸습니다. 동작에는 문제가 없었지만 완성도가 떨어져, 실제 일러스트(`prop-ink-monster`)로 교체했습니다. 양피지 질감과 '만약에' 레버도 같은 방식으로 그림 에셋을 준비했습니다.

## 영상: 4K HEVC → 720p H.264

인트로와 엔딩 영상이 원래 4K HEVC였는데, 구형 태블릿과 일부 브라우저에서 아예 재생되지 않거나 버벅였습니다. 태블릿 화면에서는 차이가 보이지 않는 720p H.264로 재인코딩해 호환성과 로딩 속도를 함께 잡았습니다.

## 3D 단서: 90MB → 21MB

단서 GLB 전체가 약 90MB로, 교실 와이파이에서 첫 로딩을 감당하기 어려웠습니다. meshopt 무손실 압축으로 시각 품질을 그대로 유지한 채 21MB까지 줄였습니다.

## 퇴고 UX 단순화

퇴고 화면이 처음에는 문장마다 번호 블록을 붙이는 방식이었는데, 학생 입장에서 "몇 번을 고칠까"를 먼저 따지게 되어 흐름이 끊겼습니다. 문장을 직접 눌러 하이라이트하고 바로 고치는 방식으로 바꿔 조작 단계를 줄였습니다.

## 저사양 태블릿 자동 라이트 티어

기기 메모리와 CPU 코어 수를 확인해 저사양 기기에서는 개당 약 1MB의 라이트 GLB(`models/lite/`)를 자동으로 불러옵니다. 교사가 따로 설정할 것 없이, 같은 링크 하나로 고사양·저사양 태블릿이 섞인 교실을 감당하기 위한 장치입니다.
