### OFL 조건 이행 현황

OFL 1.1 은 **상업적 이용과 유료 소프트웨어 번들 판매를 명시적으로 허용**합니다
("...to use, study, copy, merge, embed, modify, redistribute, and **sell** modified and
unmodified copies of the Font Software"). 지켜야 할 조건은 다음 넷입니다.

| 조건 | 내용 | 이행 |
|---|---|---|
| 1 | 폰트를 **그 자체로만** 판매 금지 | 해당 없음 — 게임에 번들 |
| 2 | 배포 시 **저작권 고지 + 라이선스 원문 동봉** | ✅ `public/fonts/*-OFL.txt` 로 동봉 |
| 3 | 수정본에 Reserved Font Name 사용 금지 | 해당 없음 — 원본 그대로 사용 |
| 4 | 제작자 이름을 홍보에 사용 금지 | 해당 없음 |

**앱 화면에 폰트 크레딧을 표시할 의무는 없습니다.** (조건 2는 파일 동봉으로 충족)
폰트를 교체하거나 서브셋으로 가공할 경우, 가공본도 OFL 로 유지해야 하며
Pretendard 는 RFN 이 있으므로 이름을 바꿔야 합니다.
