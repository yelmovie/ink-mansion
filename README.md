# 잉크저택 (Ink Mansion)

초등 5~6학년 국어 · 창의 글쓰기 × 방탈출 태블릿 웹게임.
**같은 저택에서 시작하지만, 같은 이야기는 하나도 없다.**

단서를 모으고(탐색) → 관계를 추리하고(해석) → 예상 밖 사건을 만나고(변주) →
발단·전개·절정·결말로 쓰고(창작) → 퇴고해 한 권의 책으로 제본한다(완성).
최종 산출물은 A4 한 장(공백 포함 약 1,200자) 분량의 학생 창작 단편.

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm run verify   # 타입검사 + 데이터 검증 + 테스트 + 폰트 서브셋 + 빌드
```

## 구조

- `src/pages/` — 10개 방 (Phaser Scene + DOM 오버레이 한 쌍씩)
- `src/data/` — 모든 게임 콘텐츠(JSON). 코드 수정 없이 내용 교체 가능
- `src/state/` — localStorage 저장 (`ink-mansion:save:v1`, 스키마 마이그레이션 포함)
- `public/models/` — 단서 3D(GLB, meshopt 압축). 없으면 자동으로 2D 폴백
- `_source/` — 원본 에셋 (배포 제외)

## 원칙 (PRD 발췌)

- 모범 문장을 먼저 보여주지 않는다 · 정답 서사를 만들지 않는다
- 학생 글은 기기 밖으로 나가지 않는다 (백엔드 없음)
- 30명이 같은 결과로 수렴하지 않는다 (시드 랜덤 + 자유 입력)
